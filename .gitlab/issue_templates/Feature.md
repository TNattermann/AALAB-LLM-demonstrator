# ✨ Feature Request

## Is your feature request related to a problem?
A clear and concise description of what the problem is. Ex. "I'm always frustrated when [action]..."

## Describe the Solution
A clear and concise description of what you want to happen.

## Describe Alternatives Considered
A clear and concise description of any alternative solutions or features you've considered.

## Use Case (Optional)
Describe the users who will benefit and how they will use this feature. This helps prioritize the feature.

## Additional Context
Add any other context, wireframes, or screenshots about the feature request here.
